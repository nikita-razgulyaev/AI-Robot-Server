# Управление: геймпад, панель, голос, автономный режим

## Режимы

| Режим | Кто двигает | Геймпад |
|---|---|---|
| **manual** (по умолчанию) | Человек | Активен |
| **autonomous** | Робот / панель-override | Отключён |

Модуль: `modules/control_mode.py`.

### Переключение

1. **Панель** → вкладка «Движение» → Ручное / Автономное  
2. **Команда** `{type:"set_control_mode","mode":"autonomous","reason":"panel"}`  
3. **Голос** (quick_answers):
   - «режим ручной», «управление с геймпада» → `manual`
   - «режим автономный», «управляй сам» → `autonomous`

В будущем любой новый источник (LLM tool-call, планировщик) вызывает тот же `control_mode.set(...)`.

## Раскладка геймпада (DualShock 4)

Подстройте индексы в `modules/gamepad_input.py` под свою модель (`python -m pygame.examples.joystick`).

| Элемент | Назначение |
|---|---|
| Левый стик Y (LY) | Вперёд / назад → `walk` |
| Левый стик X (LX) | Поворот → `turn` |
| Правый стик RX/RY | Резерв |
| ✕ | Взлёт |
| ○ | Посадка |
| □, △, L1, R1 | Не назначены |
| L2, R2 (аналоговые, 0–100%) | Не назначены |

Схема на панели (вкладка «Движение») показывает положение стиков, нажатие кнопок и значения триггеров в реальном времени (`gamepad_state` по WebSocket).

## Панель — вкладка «Движение»

- Переключатель режима  
- Кнопки «2 шага вперёд» (`walk`, `steps: 2`) и «Пролететь 5 м» (`fly`, `distance_cm: 500`)  
- Схема геймпада: стики, ✕ ○ □ △, L1/R1, полоски L2/R2  

Заданные движения не прерываются, кнопки «Стоп» в панели нет.

## Быстрые ответы и SFX

`character/quick_answers.json`:

- `control_mode_manual` / `control_mode_autonomous` — голос + смена режима  
- `motion_takeoff` / `motion_land` — sfx при взлёте/посадке (пути `sfx/*.wav` — положите файлы или уберите поле)  
- `bait_curious` — «затравки» без LLM  

Конвейер: матч quick_answers → (опционально) смена control_mode → текст + emotion + action + sfx/audio → TTS fallback если нет audio.

## Safety

- `emergency_stop` и `return_to_default` доступны всегда, в любом режиме.  
- Взлёт блокируется, если behavior считает, что нет стойки на опоре (`can_takeoff`).  
- Потеря опоры без self-flight → Priority.SAFETY.
