# Локомоция: углы, фазы, как настраивать

## Карта серв (индекс 0–21)

| CH | Имя | Назначение |
|----|-----|------------|
| 0 | L_WING_FLAP | Левое крыло — взмах |
| 1 | L_WING_FOLD | Левое крыло — складывание |
| 2 | L_WING_TILT | Левое крыло — наклон |
| 3 | R_WING_FLAP | Правое крыло — взмах |
| 4 | R_WING_FOLD | Правое крыло — складывание |
| 5 | R_WING_TILT | Правое крыло — наклон |
| 6 | L_LEG_TURN | Левая нога — поворот |
| 7 | L_LEG_HIP | Левая нога — бедро |
| 8 | L_LEG_SHIN | Левая нога — голень |
| 9 | L_LEG_TARSUS | Левая нога — цевка |
| 10 | R_LEG_TURN | Правая нога — поворот |
| 11 | R_LEG_HIP | Правая нога — бедро |
| 12 | R_LEG_SHIN | Правая нога — голень |
| 13 | R_LEG_TARSUS | Правая нога — цевка |
| 14 | TAIL_YAW | Хвост — поворот |
| 15 | TAIL_SPREAD | Хвост — раскрытие |
| 16 | TAIL_LIFT | Хвост — подъём |
| 17–21 | HEAD_*/BEAK/PELVIS_* | Голова, клюв, таз (уточните под механику) |

Нейтраль: **90°** на всех каналах.

## Как задавать углы циклов

Файл: **`modules/motion_primitives.py`**.

### 1. Точечная правка каналов

```python
from modules.motion_primitives import patch

pose = patch({2: 60, 5: 120})           # CH02=60, CH05=120
pose = patch({"TAIL_YAW": 110})         # по имени
pose = patch({"CH14": 70, 7: 80})       # смешанно
```

### 2. Один цикл шага (`SINGLE_STEP`)

Сейчас заглушка по вашим данным (правая → левая через CH02/CH05):

```
time 0     нейтраль
150        CH02: 60          # правая
300        CH02: 60, CH05: 120
450        CH02: 120
600        CH02: 60          # левая
750        CH02: 90
900        CH02: 60
1000       нейтраль
```

**Меняйте** список `SINGLE_STEP` в `motion_primitives.py`.  
Первый и последний кадр должны сходиться, иначе на стыке повторов будет рывок.

### 3. Взмах (`SINGLE_FLAP`), поворот (`SINGLE_TURN_TICK`)

- Взмах: каналы 0 и 3 (`L/R_WING_FLAP`) — заглушка 50° ↔ 130°.
- Поворот: `TAIL_YAW` (CH14). Знак угла в `build_turn` зеркалит yaw.

### 4. Взлёт / посадка

`TAKEOFF` / `LANDING` — одноразовые списки кадров (не циклы).  
Подставьте реальные углы приседа, толчка, поджатия лап.

### 5. Физика «сколько см за шаг»

```python
STEP_LENGTH_CM = 5.0      # см за один SINGLE_STEP
FLAP_ADVANCE_CM = 15.0    # см за один SINGLE_FLAP
TURN_STEP_DEG = 15.0      # ° за один SINGLE_TURN_TICK
```

Замерьте на полу/в воздухе и поправьте.

## Таблица параметров (раздел 4) — заглушки

| Примитив | Где править | Ключевые каналы (заглушка) | Длительность цикла |
|---|---|---|---|
| Шаг | `SINGLE_STEP` | CH02, CH05 | 1000 мс |
| Взмах | `SINGLE_FLAP` | CH00, CH03 | 600 мс |
| Поворот | `SINGLE_TURN_TICK` | CH14 TAIL_YAW | 400 мс |
| Взлёт | `TAKEOFF` | CH07/11 бедро, CH00/03 крылья | 750 мс |
| Посадка | `LANDING` | CH16 хвост, CH07/11/08/12 лапы | 700 мс |

Чеклисты: `docs/checklists/чеклист_ходьба_полёт.txt`, `чеклист_взлёт_посадка.txt`.

## Вызов из кода / панели / геймпада

```python
frames = motion_primitives.build_walk(40)   # 40 см
await servos.play_motion(frames, on_frame=on_servo_frame)
```

Команды: `{type:"walk","distance_cm":10,"source":"panel"}`, `fly`, `turn`, `takeoff`, `land`.

Кнопка **↩ В 90°** на вкладке «Сервоприводы» — плавный возврат (`smooth_return_to_default`).
